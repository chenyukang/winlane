## What's new

- **Command aliases:** in **Settings → Aliases**, a rule can now bind one or two letters to a built-in Winlane command instead of only an app or project window. Add a rule, choose **Command** as its type, select the command, and enter the alias letters. Typing that alias in search lists the command first, the same way an app alias surfaces an app. Each alias maps to a single target, so a letter cannot be shared between an app and a command, and command rules ignore the window-title filter. Existing app and project aliases are unchanged. See [built-in commands](https://github.com/chenyukang/winlane/blob/v0.9.4/docs/commands.md).

## Improvements and fixes

- **Auto AppClose:** the per-app window limit introduced in 0.9.3 is now named **Auto AppClose** in Settings and the documentation. Its rules, limits, protected windows, and timing are unchanged, and existing configurations carry over.
- **File actions keyboard control:** in the `files` **Actions ⌃T** menu, use the arrow keys to select an action and **Enter** to run the highlighted item. Escape still dismisses the menu while keeping the file search open, and actions apply to the item selected when the menu opened.
- **Tighter panel spacing:** the search and switch panels use a slimmer, balanced bottom margin when no hint, settings button, or error message is shown, ending the window closer to the last result. The footer row still reserves its space whenever it appears.

Existing settings, snippets, Quicklinks, and clipboard history are preserved when upgrading.
