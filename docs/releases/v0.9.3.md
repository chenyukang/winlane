## What's new

- **File search:** run `files` to find files and folders by name, fuzzy abbreviation, or path. The picker opens with cached results while searches run in the background, and remembers the last 25 items opened through Winlane. Type patterns such as `~/Downloads/*.pdf` to search a directory recursively; wildcard and regular-expression matching work automatically, with literal matches ranked first. Configure search folders and exclusions in **Settings → Files**. Keyword searches use Spotlight; explicit paths can browse folders without it.
- **Emoji picker:** run `emoji`, search English or Chinese names and keywords, and press **Enter** or click a result to paste it into the app you were using. The chooser starts with common emoji and preserves complete sequences, including skin tones and joined characters. All 3,781 emoji entries and their search data are embedded in Winlane for offline use; rendering uses the emoji supported by your macOS version. Assign a direct shortcut in Settings.
- **Keep Awake:** run `keep-awake` or `caffeine` to prevent idle sleep for 30 minutes, 60 minutes, or until turned off. Choose whether the display may sleep. A persistent coffee badge shows the active mode and remaining time, including on full-screen Spaces. Reopening the picker selects the active option without restarting its timer. Sessions end when their timer expires, you turn them off, or Winlane quits; they do not override closing the lid or manually putting the Mac to sleep.
- **Mouse and trackpad scrolling:** enable custom scrolling in **Settings → Mouse Scrolling** to reverse vertical and horizontal directions independently for each device type and adjust discrete mouse-wheel steps. Changes apply immediately without changing macOS's Natural Scrolling preference. This feature is off by default; turn off other scroll-modifying utilities before enabling it.
- **Auto Cleanup:** set a window limit for each app in **Settings → Auto Cleanup**. When enabled, Winlane closes excess eligible windows in least-recently-used order, one at a time. Checks run every 10 seconds by default, with a configurable interval and a new-window grace period of twice that interval. The active window and windows reported as having unsaved edits are protected. Cleanup uses normal close requests and never answers save/discard prompts; protected or unavailable windows may keep an app above its limit. The global switch is off by default.

## File navigation and actions

- **Tab** completes the selected path. **Enter** browses into a folder or opens a file; **Control + Enter** opens a folder in Finder.
- **Control + Backspace** removes the last path component, so `~/Downloads/` becomes `~/`.
- **Control + T** opens the actions menu. **Command + Enter** reveals the selection in Finder, and **Command + Y** shows Quick Look inside the picker.
- **Command + C** copies the file; **Command + Shift + C** copies its path.
- **Esc** closes the picker. Empty Backspace stays in the command, and all input follows Winlane's existing input-source rules.

## Improvements

- **Configurable logging:** **Settings → General → Logging** now offers Debug, Info, Warn, Error, and Off, plus a custom log-file path. The default is Info at `~/Library/Logs/Winlane/winlane.log`, with bounded rotation. Auto Cleanup records close requests, confirmed closures, and failures separately. Diagnostic entries omit window titles, typed text, and clipboard contents.
- **Glass Settings:** the Settings window now uses Winlane's shared glass/blur backdrop, including the title-bar area, with the sidebar blended into the same window. Light and dark appearances remain supported.
- **Local development updates:** added an installation helper that verifies signatures and executable hashes, preserves settings and a backup, restarts the app, and attempts rollback if replacement or startup fails. Launches from Codex also remove transient terminal environment settings before starting the app.
- **Clearer documentation:** the README is organized around everyday tasks, with new guides for Files, Keep Awake, scrolling, and Auto Cleanup.

Existing settings, snippets, Quicklinks, and clipboard history are preserved when upgrading. Auto Cleanup and custom scrolling remain opt-in.
