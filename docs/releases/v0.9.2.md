## What's new

- **Bluetooth devices:** run `bluetooth` or `bt`, select a paired device, and press **Enter** to connect or disconnect it. Headphones and speakers appear first. Connection requests run in the background with progress and errors shown in the picker. Assign a direct shortcut in **Settings → Shortcuts → Command shortcuts**.
- **Input rules:** choose a global input source and per-app overrides in **Settings → Input Rules**. Each app can use its default source on activation or restore its last-used source. Automatic switching for other apps is opt-in. Winlane has its own always-active rule, defaulting to English for new installations; existing input preferences migrate automatically, retaining early-keystroke buffering and composition handling.
- **Input source indicator:** optionally show the active input source as a color bar, name badge, circle, or rounded rectangle. Customize colors and visibility per source, dimensions, display selection, screen position, and X/Y offsets. Hide the indicator for sources such as ABC while keeping it visible for others. The indicator is disabled by default and lets clicks pass through.

## Improvements and fixes

- **Automatic app discovery:** installing, removing, moving, or renaming an app in the standard Applications folders now refreshes the search catalog in the background. Newly installed apps no longer require restarting Winlane or manually refreshing. Updates preserve the current query and selection.
- **Faster project browsing:** `projects` saves the 25 most recent projects locally and restores them in the background after a restart. The picker shows cached results or a loading indicator immediately, remains usable during refresh, and limits visible rows to keep large histories responsive. Typing still searches all loaded projects.
- **Project window focus:** after opening a VS Code project, Winlane waits for the matching window, restores it if minimized, and brings it forward. Existing normal/fullscreen layouts are preserved. Reopening Winlane or switching to another app cancels the pending focus action.
- **Better URL ranking:** `open-url` prioritizes domain matches over matches in page titles, paths, or parameters. Exact domains rank before prefixes and substrings, with recent visits breaking ties. For example, `you` puts YouTube domains ahead of unrelated titles containing “you”.
- **Consistent command navigation:** **Esc** closes command views directly. **Backspace** only deletes text and stays in the current command when the input is empty; use the back button to return to ordinary search.
- **Fresher window lists:** closed windows are removed sooner, and a slower background scan cannot reintroduce an already-closed window. The remaining switcher order and selection are preserved where possible.
- **Lighter, clearer Settings:** pages are created on demand, and heavier editors are released when Settings closes. Alias rules are now edited directly in Settings. Alias and input-rule editors use a compact list-and-detail layout, with unfinished alias drafts retained when reopening Settings.
- **Settings activation:** improved reliability when bringing an existing Settings window forward with **Command + ,** from search, including windows on another Space or minimized windows.

Existing settings, snippets, Quicklinks, and clipboard history are preserved when upgrading.
