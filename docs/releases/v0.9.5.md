## What's new

- **Meeting schedule:** run `meeting` (or search `calendar`, `会议`, `日程`) to list today's events from the macOS Calendar and open a meeting link. The list opens in its own scoped view with cached rows or a loading state, and reads events in the background. Each row shows the start time, a countdown such as **Starting in 20 minutes**, the event title, and the detected join link or location; press **Enter** to open it in your default browser. Press **`>`** for the next day and **`<`** for the previous day, **⌘R** to refresh, and Esc to return to search. The whole day is shown sorted by start time: finished meetings are marked **Completed**, an ongoing one **In progress**, and upcoming ones show a countdown. Links are detected for Zoom, Google Meet, Microsoft Teams, Webex, Whereby, Jitsi, BlueJeans, Chime, GoToMeeting, RingCentral, Tencent Meeting, and Feishu/Lark. Winlane reads events through EventKit and requests Calendar access on first use; it only displays events and never creates, edits, or deletes calendar data. See [Meetings](https://github.com/chenyukang/winlane/blob/v0.9.5/docs/meeting.md).

- **Git branch switching:** run `branch` (or `git branch`, `checkout`) to list the local branches of the VS Code project you were working in, and press **Enter** to switch with `git switch`. Winlane finds the repository from the frontmost VS Code window when possible and falls back to your recent projects. The current branch is marked with `*`, and branches checked out in another worktree are labeled. If the working tree has uncommitted changes or the branch is held by another worktree, Git's message is surfaced unchanged — Winlane never auto-commits. See [Branch](https://github.com/chenyukang/winlane/blob/v0.9.5/docs/git-branch.md).

- **Time indicator:** in **Settings → Indicator**, enable **Always show the current time** to keep a small time badge on screen, refreshed every second. Pick a position, size, and color, and fine-tune X/Y offsets just like the input-source indicator. It follows displays and Spaces, stays visible over full-screen apps, lets clicks pass through, and the Keep Awake badge moves out of its way. Off by default.

- **`date` command:** type `date` (or `time`) to see the current local date and time as a search result, formatted like `2026-9-23 18:06:55`. The row keeps updating as you type, and selecting it copies the shown timestamp to the clipboard and closes the picker without pasting into another app.

## Improvements and fixes

- **Indicator display choice:** the input-source indicator's **Displays** option now offers **All displays**, **Main display**, and **Non-main display** instead of a simple on/off switch. Existing settings carry over: the previous choice becomes All displays or Main display respectively.
- **Settings → Indicator:** the former **Input Indicator** page is now named **Indicator** and hosts both the input-source indicator and the new time indicator.

Existing settings, snippets, Quicklinks, and clipboard history are preserved when upgrading.
