## What's new

- **Built-in commands:** run `lock-screen`, `sleep`, `mission-control`, `show-menu`, `screenshot`, and `toggle-appearance` from search. Select an area for screenshots, temporarily reveal the macOS menu bar, or switch the system between light and dark mode.
- **Snippets:** create and edit reusable text inside Settings, then search for `snippet` to find and paste it into the previous app. Add clipboard text, date/time presets, custom date formats, and named text, multiline, or dropdown fields with defaults and required-field validation. Snippets have their own search view so they do not displace window aliases.
- **Clipboard history:** search for `clipboard` to find and reuse copied text, links, and PNG/TIFF images. Image entries include thumbnails and paste as images. History is stored locally across restarts, with a default limit of 200 entries for 7 days; recording, storage, retention, and deletion controls are in Settings → Clipboard.
- **Quicklinks:** save websites, app links, files, and folders, or import a Raycast Quicklinks JSON export. Search by name or enter the dedicated `quicklink` view. Links support clipboard, date, and input placeholders; fill parameters directly inside the search panel without opening another dialog.
- **Recent VS Code projects:** search for `projects` or `vscode` to browse and reopen recent local folders and workspaces, even when their windows are closed. Filter by project name or path; Command + R refreshes the list.
- **Multiple search shortcuts:** assign up to eight search bindings in Settings → Shortcuts. Command + Space is now supported; reassign Spotlight or another launcher if it uses the same combination. Existing saved bindings are preserved.

## Interface and behavior

- Reorganize Settings into a sidebar with General, Appearance, Shortcuts, Input, Windows, Aliases, Snippets, Clipboard, and Quicklinks sections. Snippet and Quicklink editing stays in the same Settings window, with automatic saving.
- Use a lighter, uniform translucent selection highlight in place of the blue-to-teal gradient. Improve vertical text alignment in result rows and slightly enlarge the search field in Normal density.
- Remove explanatory text from the Shortcuts settings page and tighten its layout.
- Start searches in English by default for new configurations. Updates preserve an explicitly saved input-source preference; Chinese, current input source, and last used in Winlane remain available.

## Fixes

- Record system screenshots copied to the clipboard while Winlane is in front, including screenshots of its own settings and panels. Generated snippet and history pastes remain excluded to avoid duplicate records.
- Make settings-window tests independent of AppKit's hidden auxiliary windows, fixing the macOS CI failure on both architectures.
- Report the failing command and build stage when ZIP or DMG packaging fails in CI.

## Updating

Existing settings, aliases, snippets, Quicklinks, and clipboard history remain in their current local storage when replacing the app. Install at the same location, or use **Check for Updates…** from Winlane's menu.
