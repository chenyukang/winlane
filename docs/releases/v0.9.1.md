## What's new

- **Open URL:** run `open-url` to search Chrome history by title, domain, or URL, ordered by the latest visit. The first match is selected automatically; **Enter** opens it in a new Chrome tab. **Control + Enter** opens the address you typed or searches Google, regardless of the selected result. Enter uses the same fallback when no history item matches. History stays in its own command view, with clear access-permission errors and a retry action.
- **Command shortcuts:** assign global shortcuts in **Settings → Shortcuts → Command shortcuts** to open tools such as `open-url`, `projects`, and `clipboard`, or run system commands directly.
- **Quicklink shortcuts:** configure a global shortcut in a Quicklink's details. Links open directly, while links with parameters open their input fields inside Winlane. Shortcut conflicts now identify the existing command, Quicklink, app, or search/switch binding, including reverse switching.

## Improvements and fixes

- **Faster panel presentation:** search displays cached results while window and application data refresh in the background. `projects` and `open-url` also show their cached lists immediately and preserve selection during refresh. Switch mode continues to respect its configured display delay.
- **Consistent input sources:** search, command inputs, inline Quicklink arguments, Settings editors, and snippet forms follow the same input-source preference. English remains the default; existing preferences are respected. Startup handling preserves early keystrokes, avoids briefly sending English input to the previous IME, and keeps Chinese composition intact during result refreshes.
- **More reliable recent-window order:** recover from missing or delayed focus information without letting stale results overwrite newer activity. Save the order on normal exit and restore it after restarting Winlane for windows that are still open.
- **Native glass panels:** use the system glass material where available, with a frosted fallback on older macOS versions. Text and icons remain fully opaque.
- **Dark-mode Settings:** shared cards and borders now use adaptive system colors, fixing overly bright backgrounds across Settings and when switching themes.
- **Control + Enter:** intercept macOS's context-menu shortcut in `open-url` so it submits the typed address or search instead of opening the input's right-click menu.

## Maintenance

- Reorganized the source into core logic, feature modules, macOS platform integrations, and UI components. Expanded automated coverage for input startup, cached command loading, window order, shortcut conflicts, and appearance changes.

Existing settings, snippets, Quicklinks, and clipboard history are preserved when upgrading.
