## What's new

- **Key remaps:** Winlane can rewrite a key combination for every application, the way a keyboard remapper does. **Settings → Shortcuts → Key remaps** lists each rule with its own switch, an **Enable key remaps** master switch, and the applications that rule leaves alone. Pick those from an application panel instead of typing bundle identifiers, or add the usual terminal and remote-desktop lists in one step. Rules stay plain — one key plus its modifiers becomes another key plus its modifiers — and a combination you gave Winlane is never taken over, so a migrated rule cannot shadow an app shortcut. Already using Karabiner-Elements? `python3 scripts/migrate-karabiner.py` converts plain remap rules, including their per-application exclusions. See [Key remaps](https://github.com/chenyukang/winlane/blob/v0.9.6/docs/key-remaps.md).

- **A new look:** the app icon and the menu-bar mark are a pack of glossy tool chips, and the menu-bar mark is now a two-by-two grid that stays readable at true menu-bar size.

- **Clipboard history follows your use:** pasting an entry moves it to the top of the list, so the entries you reuse stay within reach instead of staying where they were originally copied. Copy times, retention, and the 200-entry limit are unchanged.

## Improvements and fixes

- **Switching to a stale window:** selecting a window whose accessibility handle an app invalidated now finds the same window again by its WindowServer identity and retries, instead of failing the switch.
- **Accessibility failures explain themselves:** a switch that cannot complete now names the likely cause and the next step — permission, an invalid window, a busy app — instead of a bare error code.
- **Solid background option:** **Settings → Appearance** can replace the frosted glass panel material with a flat tint, which uses noticeably less graphics memory at the cost of the blur.
- **Settings opens on the sidebar:** opening Settings no longer puts the caret in the log-path field with its value selected.
- **Lower icon memory:** window icons are cached at the size they are drawn (96 px) instead of 256 px.
- **Settings layout:** a native test now fails when two controls on a settings page overlap. It caught the display card growing over the heading below it.
- **Build reproducibility:** the Rust toolchain is pinned to the version CI uses, so local and CI builds share a compiler.

Existing settings, snippets, Quicklinks, and clipboard history are preserved when upgrading.
